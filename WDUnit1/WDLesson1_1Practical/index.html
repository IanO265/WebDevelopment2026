Web Technologies

Html

HTML, or HyperText Markup Language, is the standard markup
language used to create and structure web pages.
It uses a system of tags and elements to organize text,
images, and links so that web browsers know how to display them.

CSS

The CSS is a stylesheet language used to control
The visual presentation and layout of web documents wrtitten
in HTML It works by targeting specific HTML elements with
selectors to define properties like colors, fonts, and spacing.

JavaScript

JavaScript is a core programming language used to make web pages
interactive and dynamic It works alongside HTML and CSS to handle
user actions like clicks, animations, and instant updates without reloading the page.
